# ExtremeLand Launcher

**Temporada 1 · La Rueda Rota**

Launcher para Windows de 64 bits, Minecraft Java 1.20.1 y Forge 47.2.0. Descarga y actualiza el paquete de mods antes de jugar.

[Descargar launcher](https://github.com/JRaudales-hue/extremeland-launcher/releases/latest/download/ExtremeLandLauncher.exe) · [Ver versiones](https://github.com/JRaudales-hue/extremeland-launcher/releases)

El enlace de descarga funciona cuando la primera release termina de publicarse.

## Cómo entrar

1. Descarga y abre ExtremeLandLauncher.exe.
2. Pulsa Actualizar para preparar el paquete. La primera descarga es grande: unos 1.55 GB de mods, además de Minecraft y sus componentes.
3. En Cuenta Microsoft, conecta tu cuenta comprada de Minecraft mediante Prism Launcher: Configuración → Cuentas → Añadir Microsoft.
4. Cierra la ventana de acceso y pulsa Jugar.
5. El anfitrión abre el mundo y envía la invitación con Essential.

El launcher no solicita contraseñas Microsoft. Prism Launcher gestiona el inicio de sesión y la instalación de Java, Minecraft y Forge.

## Actualizaciones y mundos

Cada vez que pulsas Jugar se comprueba la versión publicada. Se descargan completos los JAR que hayan cambiado, se verifican por SHA-256 y se guardan copias de los mods anteriores. Los mundos locales se conservan.

Jefferson publica las actualizaciones desde Herramientas del creador y GitHub Releases. Los amigos no necesitan cuenta de GitHub. El launcher no mantiene un servidor encendido: el anfitrión debe estar conectado para jugar juntos por Essential.
